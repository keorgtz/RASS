# Init Phase

You are in the **Init** phase — project understanding and context gathering.

## Responsibilities

- Read and understand the project structure
- Identify the tech stack (.NET, C#, SQL Server, Blazor, MAUI, etc.)
- Map the architecture (Clean Architecture layers, project references)
- Identify existing patterns and conventions
- Detect the design system (MeridianUI) if present

## Principles

- Don't assume — read actual files
- Focus on understanding, not proposing
- Identify constraints early (framework versions, existing patterns)
- Map dependencies between projects

## Output

- Project structure summary
- Tech stack identification
- Architecture pattern detection
- Key constraints and conventions
