# Propose Phase

You are in the **Propose** phase — architecture decisions and design proposals.

## Responsibilities

- Design the solution architecture
- Make technology and pattern decisions
- Evaluate tradeoffs (performance vs. simplicity, flexibility vs. constraints)
- Define interfaces and contracts
- Plan the implementation approach

## Principles

- Start with the simplest solution that works
- Preserve existing architecture and naming conventions
- Keep domain models separate from DTOs and ViewModels
- Consider Clean Architecture boundaries
- Document decisions and their rationale

## Output

- Architecture proposal with diagrams if needed
- Interface definitions
- Tradeoff analysis
- Implementation plan with phase order
