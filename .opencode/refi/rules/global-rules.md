 # REFI Global Rules

 1. Move immediately.
 2. Create the REFI packet before broad implementation.
 3. Keep scope explicit.
 4. Implement incrementally.
 5. Verify before progressing.

 Mandatory order:

 1. Preserve request.
 2. Build master blueprint.
 3. Build domain shards.
 4. Build orchestration map.
 5. Implement shard 1.
 6. Verify shard 1.
 7. Continue.
