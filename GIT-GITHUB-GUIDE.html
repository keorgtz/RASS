Guía rápida para commitear y pushear a GitHub

Uso básico desde consola para este repositorio.

1. Ver qué cambió

git status

2. Agregar archivos al commit

git add .

Si prefieres algo más seguro, agrega archivos específicos:

git add README.md installer/package.json GIT-GITHUB-GUIDE.html

3. Crear el commit

git commit -m "Describe brevemente tus cambios"

Ejemplo:

git commit -m "Fix Linux CLI install docs and add GitHub guide"

4. Ver tu rama actual

git branch --show-current

5. Pushear a GitHub

Si tu rama ya existe en remoto:

git push

Si es la primera vez que subes esa rama:

git push -u origin TU-RAMA

Flujo rápido completo

git status

Si estás en Master o main

git push -u origin Master

O cambia Master por main si esa es tu rama principal.

Comandos útiles

git log --oneline -10      # últimos commits

Errores comunes

  • "nothing to commit": no agregaste o no modificaste archivos.
  • "no upstream branch": usa git push -u origin TU-RAMA.
  • auth error: inicia sesión con GitHub CLI o usa tu token/credenciales.

Recomendación simple

Para el día a día usa:

git status
