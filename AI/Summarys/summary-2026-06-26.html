✦ Qué se implementó

REASP era exclusivo de Windows. En esta sesión se añadió soporte completo para Linux y macOS de forma aditiva — el código Windows se preservó intacto. Adicionalmente, se implementó el instalador global de MeridianUI para ambas plataformas.

  • Bug crítico corregido: URL file:////home/... (4 barras) → file:///home/... (3 barras) usando pathToFileURL().
  • Detección Linux: unixPaths[] ya existía; se agregó ~/.volta/bin/opencode para usuarios Volta.
  • MeridianUI installer: nuevo módulo meridianui.js — copia .MeridianUI/ del repo a ~/.MeridianUI/ en Windows y Linux.
  • Placeholder: .MeridianUI/.gitkeep en raíz del repo para que el usuario deposite el contenido UI cuando esté listo.
  • Execute bit: scripts/reasp mode 100755 en git index (ejecutable sin chmod manual post-clone).
  • Line endings: .gitattributes — LF para scripts Unix, CRLF para .cmd Windows.
  • Documentación: README (sección Linux + MeridianUI), AGENTS.md (rutas Linux + Volta), TROUBLESHOOTING.md (casos Linux).

● Decisiones técnicas importantes

  • Aditivo, no reemplazante: winPaths[] y todo el código Windows se preservó sin tocar. Linux se agregó en el bloque else del if(win32) ya existente.
  • pathToFileURL(): la API nativa de Node genera automáticamente file:///C:/... en Windows y file:///home/... en Linux — sin lógica condicional adicional.
  • fs.promises.cp(): copia recursiva cross-platform disponible desde Node 16.7 — funciona idéntico en Windows y Linux.
  • MeridianUI como pre-step: corre una sola vez antes de instalar cualquier agente, sin importar cuántos se seleccionen.
  • Warning, no error: si .MeridianUI/ solo tiene .gitkeep, el installer advierte y continúa — no falla.
  • uninstall no borra ~/.MeridianUI/: el design system instalado globalmente sobrevive a la desinstalación de REASP.
