16 de junio de 2026 · Multi-agente + CLI global + Backup Manager

✦ Qué se implementó

REASP evolucionó de un instalador local de OpenCode a una herramienta de sistema global con capacidades de respaldo.

  • Compatibilidad multi-agente: OpenCode, Claude Code, Codex, Gemini CLI y Antigravity CLI.
  • CLI global: comando reasp instalable vía npm install -g ..
  • Backup Manager: snapshots completos por agente, con restore, delete y purge.
  • TUI unificado: menú principal con acceso a install, uninstall, snapshots, detect y status.
  • Documentación: README, AGENTS.md y TROUBLESHOOTING.md actualizados.

Luego, desde cualquier terminal:

● Decisiones técnicas importantes

  • Una fuente de verdad: los assets canónicos permanecen en .opencode/; los adaptadores traducen al formato nativo de cada agente.
  • Snapshots completos: se copia todo el directorio de configuración del agente, no solo los archivos que toca REASP.
  • Restore atómico: usa renombrado temporal y rollback automático en caso de fallo.
  • Backups independientes: los snapshots viven en ~/.reasp/snapshots/ y sobreviven a desinstalaciones.
  • Degradación elegante: agentes sin plugins/MCP reciben el comportamiento REASP como system instructions.
